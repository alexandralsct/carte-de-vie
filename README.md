# Ma carte de vie

Application web installable (téléphone, ordinateur) pour organiser sa vie par « espaces » autour d'un rond « Moi ».

- Ouvrir l'adresse du site dans Chrome, puis menu > « Installer l'application ».
- Sans réglage, les données restent dans l'appareil. « Exporter » et « Importer » (Réglages) servent de sauvegarde.
- La synchronisation entre appareils (Réglages → Synchronisation) enregistre la carte dans un dépôt GitHub **privé** choisi par la personne.

Ce dépôt est **public** et ne contient que le code de l'application : aucune donnée personnelle, aucune capture de carte réelle, aucun document de projet. Voir `CLAUDE.md`.
